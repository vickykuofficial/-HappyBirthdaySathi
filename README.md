# Birthday Surprise for Sathi 🎂

A stylish, animated birthday wish website.

## How to use

1. Music and all 5 photos are built-in (in this folder) and load automatically — no manual picking needed.
2. Open `index.html` in any modern browser (double-click works; for best results serve via a local server).

## Features

- Romantic entry screen with floating emojis
- Background music with play/pause
- Animated hero with glowing avatar
- Typing love quotes carousel
- Interactive cake cutting with confetti & emoji burst
- Wishes grid
- Photo gallery (file picker or photos/ folder)
- Instagram link

## Customize

- Edit name/quotes in `script.js` and `index.html`.
- Colors in `styles.css` (`:root` variables).
